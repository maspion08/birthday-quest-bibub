BIRTHDAY QUEST — FOR BIBUB ♡

CARA MENJALANKAN
1. Extract folder birthday_quest_bibub.zip.
2. Buka folder birthday_quest_bibub.
3. Klik dua kali index.html. Website akan terbuka di browser.
   Internet diperlukan untuk font Google; tanpa internet tetap bisa berjalan dengan font fallback.

PERSONALISASI
Buka index.html menggunakan VS Code atau Notepad.
Cari bagian: // ===================== CONFIG: EDIT BAGIAN INI =====================
Ubah:
- memories: nama file foto dan caption.
- quiz: pertanyaan, options, answer, dan pesan respons.
  PENTING: nilai answer harus sama persis dengan salah satu options.
- letter: surat untuk Bibub.
- giftMessage: isi hadiah/momen lucu.

FOTO
Masukkan foto ke folder photos, lalu beri nama:
foto-1.jpg sampai foto-12.jpg
Jika foto kamu PNG, ubah ekstensi di CONFIG menjadi .png.

MUSIK
Masukkan file audio yang boleh kamu gunakan ke folder music dan beri nama:
our-song.mp3
Atau ubah musicFile di CONFIG agar sesuai nama file. Musik mulai setelah tombol Play ditekan (browser membatasi autoplay).

PUBLIKASI GRATIS DENGAN GITHUB PAGES
1. Buat akun atau login di https://github.com
2. Klik New repository.
3. Beri nama: birthday-quest-bibub
4. Pilih Public, lalu Create repository.
5. Upload index.html dan folder photos serta music (jika sudah ada).
6. Buka Settings > Pages.
7. Pada Build and deployment, pilih Deploy from a branch.
8. Pilih branch main dan folder /(root), lalu Save.
9. Tunggu proses publikasi. URL biasanya:
   https://USERNAME.github.io/birthday-quest-bibub/
10. Buka URL tersebut dari HP untuk mengetes sebelum mengirimkannya ke Bibub.

CATATAN PRIVASI
Repository GitHub Pages yang Public berarti file website dan foto yang diunggah dapat diakses publik oleh siapa pun yang memiliki URL atau menemukan repository. Jangan unggah foto atau informasi yang tidak ingin dibagikan secara publik. Jika ingin lebih privat, gunakan layanan hosting yang mendukung kontrol akses atau bagikan file lokal saja.

Semua aset foto dan musik milikmu harus kamu tambahkan sendiri. File ini tidak menyertakan lagu atau foto berhak cipta.
